## 🌟 Architecture & Features

- **Agency Design System**: Custom dark-dominant aesthetic inspired by Vercel, Linear, Framer, and Stripe with obsidian surfaces, fine 1px borders, and ambient lighting.
- **Bespoke Vector Iconography**: 100% custom inline SVG icons styled after Lucide/Phosphor systems; zero generic emojis.
- **Hero Technology Visual**: Interactive digital product architecture console with live code view, system status indicators, and 3D parallax tilt (desktop).
- **Continuous Capability Ticker**: Hardware-accelerated infinite marquee highlighting core engineering specializations.
- **Editorial Bento Services Grid**: Dynamic 7-service bento layout with click-to-sync capability that automatically populates and focuses the project inquiry form.
- **Engineering Archetypes**: Honest showcase of production delivery standards (Web SaaS Platform, Cross-Platform Mobile Experience, Scalable Cloud API Architecture, and AI Automation Pipeline).
- **Philosophy & Comparison Matrix**: High-fidelity breakdown of Traditional Agency structure vs. the EaseWorks Agile Engineering Model.
- **Engineering Roster**: Dedicated profiles across 6 core technical disciplines (Full-Stack, Frontend, Backend, Mobile, UI/UX, and AI).
- **4-Phase Delivery Timeline**: Structured Discuss &rarr; Plan &rarr; Build &rarr; Launch process.
- **Interactive Project Inquiry**: Client-side validation, error handling, WhatsApp deep-link generation, direct email, and phone contact channels.
- **Zero-Dependency Architecture**: Pure semantic HTML5, modern modular CSS3, and performant vanilla JS for lightning-fast load times.

## 🚀 Live Deployment Options

### Option 1: Vercel (Current Host)
1. Go to [vercel.com](https://vercel.com).
2. Connect your GitHub repository (`agency`).
3. Framework Preset: **Other** &rarr; Click **Deploy**.

### Option 2: Netlify Drop
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this folder (`agency`) directly into the browser window.
3. Your site will be live instantly with a free SSL `.netlify.app` URL.

### Option 3: GitHub Pages
1. Push this repository to GitHub.
2. In your repository: Navigate to **Settings** > **Pages**.
3. Under **Build and deployment > Branch**, select `main` branch and `/ (root)` folder.
4. Click **Save**.
