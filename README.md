## 🌟 Tech Stack & Features

- **Semantic HTML5 & Modern CSS3**: Custom design tokens, glassmorphic header, CSS Grid & Flexbox, smooth transitions.
- **Micro-Interactions**:
  - Desktop custom cursor with linear interpolation (lerp).
  - Hero interactive parallax visual with live code simulation.
  - 7 core service cards with hover lift, icon scaling, and peer dimming.
  - Automatic dropdown pre-selection when clicking service cards.
  - Interactive contact form with pre-filled WhatsApp link generator and email triggers.
- **Zero-Dependency Architecture**: Fast load times, zero build steps required.

## 🚀 Live Deployment Options

### Option 1: Netlify Drop (Fastest & Zero Setup — Instant URL)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this folder (`agency`) directly into the browser window.
3. Your site will be live instantly with a free SSL `.netlify.app` URL!

### Option 2: GitHub Pages (Free Hosting with GitHub)
1. Create a new repository on [github.com/new](https://github.com/new) (e.g. `easeworks-website`).
2. Run in terminal:
   ```bash
   git init
   git add .
   git commit -m "Initial EaseWorks agency website release"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
3. In your GitHub repository:
   - Navigate to **Settings** > **Pages**.
   - Under **Build and deployment > Branch**, select `main` branch and `/ (root)` folder.
   - Click **Save**. Your site will be live at `https://<your-username>.github.io/<your-repo-name>/`.

### Option 3: Vercel
1. Go to [vercel.com](https://vercel.com).
2. Click **Add New Project** and import your GitHub repository.
3. Keep default settings (Framework Preset: Other) and click **Deploy**.
